# Overview

## What this is

**Shanhe (山河, "mountains and rivers")**: a turn-based 4X strategy game set on a map of East Asia (including Siberia) and Southeast Asia. The world is fictional: nations are drawn along real province-level borders and take their flavour from the real places, but carry fictional names and never existed as states in this form.

## Why it exists

The project is a showcase of what a frontier LLM can build. That goal drives two hard rules:

- **Everything is generated by code.** No hand-made or third-party models, textures, audio or other art assets. Public geographic datasets are allowed as input data (see [06-visuals.md](06-visuals.md)).
- **It runs in a browser from a single link**, so showing it to someone costs nothing.

## Pillars

1. **Real geography as the star.** The terrain is the real terrain, rendered as realistically as procedural techniques allow.
2. **Provinces stay meaningful.** Borders are fixed at the start; a nation develops freely inside its province and expands beyond it only through war or diplomacy.
3. **A full game in about two hours.** 150 turns across six eras. Every system is cut down to keep a turn under a minute.
4. **Play to strengths.** Where procedural generation is weak (realistic people), the design avoids it instead of doing it badly: units are board-game pieces, leaders are never shown.

## Scope summary

| Area | Decision |
|---|---|
| Platform | Browser, Three.js on WebGPU with a WebGL fallback |
| Input | Mouse and keyboard, and touch |
| Mode | Single player against AI, plus an AI-only observer mode |
| Languages | Chinese and English UI |
| Session | About 2 hours, 150 turns, six eras from ancient to modern |
| Map | Hex grid, 6000–8000 hexes |
| Nations | 50, all playable; 12 run a full AI per game, the rest a simplified AI |
| City-states | 10 |
| Victory | Conquest, Science, Economic |
| Units | Xiangqi-style round pieces, one unit per hex |
| Not in v1 | Religion, espionage, great people, wonders, multiplayer, day/night and seasons |

## Originality

The user asked for a realistic 3D experience in the manner of the Civilization series. The game borrows the 4X genre and its common mechanics. It does not reproduce the Civilization series' look, UI, leaders, text or music; all visual and interface design is original.
