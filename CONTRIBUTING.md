# Contributing

Shanhe is a personal project and a showcase: its design and code are written by Claude under an orchestrated workflow. Bug reports and fixes are welcome. For ideas and design changes, open an issue first; the design in `docs/design/` is settled and changes to it are product decisions.

## How it is developed

- Every unit of work is an issue whose body is the spec, delivered as one pull request that closes it.
- `CLAUDE.md` lists the project rules. The ones that matter most for a fix:
  - no model, texture or other art asset files; everything visual is generated by code;
  - every user-facing string needs Chinese and English;
  - a design change updates the relevant doc in the same pull request.
- Build, test and lint commands are listed in `CLAUDE.md` once the code exists. A pull request must pass them.

## Commits

Conventional Commits in English, for example `fix: clamp camera zoom at map edge`.

## Pull requests

Use the pull request template. State each acceptance check you ran and its result.
